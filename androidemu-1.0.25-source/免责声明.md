# 1.0.25 源文件存档声明（重要 · 请先阅读全文）

> 本声明随 1.0.25 源文件提供。**该版本不是 fnOS 应用中心的正式/最新版本**，而是早期迭代存档，仅供技术研究与功能参考。
> 正式版本请以 **fnOS 应用中心当前发布页**为准。仓库/目录中其它版本号并存仅表示存档顺序，不代表发布状态。

---

## 一、版本性质与适用对象

1. 本目录为 **androidemu 1.0.25** 的源文件存档（含 manifest、cmd、config、wizard、app 等），与本目录旁 `androidemu_1.0.25.fpk` 对应。
2. 1.0.25 早于当前正式候选版本（如 1.0.50），**其完整性、稳定性与安全性无法得到完全保障**，且相对较新版本存在更多已知风险（见下）。
3. 仅面向：技术研究、学习参考、功能对照、二次开发验证。**不建议**用于生产环境、重要数据、对外提供服务或商业部署。

## 二、与正式版的关系（务必注意）

- 本目录的版本号与 fnOS 应用中心的正式版本**不同步**；正式版本始终以应用中心发布页为准。
- 本存档若造成任何“与商店不一致”的观感，请以应用中心版本为准；商店相关问题请走应用中心渠道，**不要**用本存档版本反馈。

## 三、该版本已知/高风险点（重要 · 基于本项目历史实测与后续版本修复记录整理）

> 以下问题在后续版本中多数已被修复或缓解，**1.0.25 不具备这些修复**，请勿以新版本行为推断本版本：

1. **安装依赖**：必须先安装 `binder_linux` 驱动，否则安装/运行失败；未满足内核 binder 条件时无法正常开机。
2. **脚本与生命周期健壮性（早期缺陷高发区）**：早期版本曾出现脚本编码/BOM/行尾问题导致的 “exec format error”、安装脚本输出污染被误判“脚本出错且原因未知”、安装进度卡住、升级删除镜像与数据、卸载残留容器/网络/镜像等。1.0.25 位于这些问题的早期阶段，其升级、卸载、重装行为**不可与新版等同预期**。
3. **GPU 与开机风险**：早期 GPU 直通存在 surfaceflinger “no suitable EGLConfig” 类启动失败风险；设备权限可能被系统重置；无 GPU 机器依赖软件渲染，性能有限。1.0.25 的自动修复能力弱于新版。
4. **镜像获取与网络**：官方仓库（Docker Hub）在国内网络直连易超时失败，需配置镜像加速源（registry-mirrors）；拉取失败会直接影响安装与升级。1.0.25 的内置回退机制有限。
5. **权限模型（早期）**：本版安卓容器以 `privileged` 特权模式运行（redroid 上游技术需要），使用即承担相应隔离风险；脚本/面板依赖 docker 属组能力。早期版本的权限声明与最小化说明不如新版完整。
6. **兼容性边界**：仅面向 x86 架构；ARM 应用依赖内置翻译层（libndk），支持有限，加固/反检测类 ARM 应用可能启动即闪退；系统为 AOSP 精简版，**不含谷歌服务（GMS）**，强依赖 GMS 的应用可能异常。
7. **音频/编码能力缺失**：内置安卓容器无音频输出设备，且缺少 Opus/HEVC 编码器；云手机画面页**开启「音频」可能导致连接异常/断连**。
8. **账号安全**：画面后台默认账号 `admin / admin123`，**首次登录后请务必立即修改默认密码**；请勿在公网直接暴露 8443/3478/5556 等端口。
9. **画面网络依赖**：云手机画面/多设备接入依赖 8443（HTTPS）、3478（TURN，TCP/UDP）与 50000-50100/UDP 媒体端口可达；重建容器后局域网 IP 变化等都可能影响连接。
10. **标识/版权**：应用图标中「redroid」文字标识源自上游项目名，其知识产权归原作者；图标整体设计由发布者完成；文字使用授权状态待确认，权利人不认可即更换。相关声明以仓库/包内 LICENSE 为准。

## 四、使用前防御措施（请逐项执行）

1. **校验文件完整性**：`androidemu_1.0.25.fpk.sha256` 与安装包核对（Windows：`Get-FileHash androidemu_1.0.25.fpk -Algorithm SHA256`）。
2. **仅在测试/隔离环境使用**：建议虚拟机或独立测试设备；不接入生产存储与重要数据卷。
3. **先装依赖**：fnOS（x86）先安装 `binder_linux` 驱动；确认内存 ≥4GB、网络可访问镜像加速源。
4. **阅读配套文档**：先读包内 `LICENSE`、`应用介绍.txt` 与本声明，再决定是否使用。
5. **改密与收敛暴露面**：登录后立即修改默认口令；仅在内网使用，不公网映射端口。
6. **预期管理**：出现崩溃、升级/卸载异常、画面断连等问题属该早期版本固有风险；先记录日志（`/var/apps/androidemu/var/*.log` 等）再反馈。
