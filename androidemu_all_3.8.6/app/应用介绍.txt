【付费说明】本应用自身免费。内置的云手机画面服务来自上游开源项目 ScrcpyOverWebRTC，其「授权管理」为第三方付费授权：免费版即可使用云手机画面、ADB 调试、文件推送等全部基础功能，仅"可添加的设备数量"受限；购买授权后仅增加可添加的设备数量，功能本身没有任何区别。相关付费与飞牛（fnOS）官方无关，费用由上游授权服务方收取。

【网络与端口】应用支持通过飞牛统一网关访问（应用中心点开即为 /app/androidemu），也支持局域网直连画面服务端口（8443/TCP）。为支持外网与手机 APP 直连，画面与调试端口（8443/TCP、3478/TCP+UDP、5556/TCP）可由使用者自行映射到公网，应用侧不做任何自动端口映射（无 UPnP/打洞）。各端口均有独立鉴权：画面服务需账号登录（默认账号 admin，首次登录后请立即修改默认口令）、ADB 默认仅监听本机须在面板手动开放、TURN 需要凭据。请自行评估公网暴露风险。

安卓模拟器（国内版）应用介绍
============================

一、简介
基于 redroid（Remote Android in Docker）的容器化安卓模拟器：在飞牛 fnOS 上用 Docker
直接运行安卓 12，无需安装虚拟机软件。支持 GPU 直通（无 GPU 条件自动回退软件渲染，
保证稳定开机）；内置穿云投屏（WebRTC）浏览器云手机画面，可远程操控本机模拟器，并支持
通过 Agent 接入多台安卓手机/设备统一管理与 ADB 调试。自 2.0.0 起为 X86/ARM 合包：
同一安装包按设备 CPU 架构自动拉取对应镜像，无需区分下载。

二、使用前条件
1. 宿主内核需具备 binder 支持（容器化安卓必需，无纯软件替代方案）：x86 设备请先在
   应用中心安装 binder_linux 驱动；多数 ARM 设备内核已内置 binder/binderfs。
2. 首次安装需联网拉取容器镜像（约 2GB），自动按顺序尝试飞牛加速源（docker.fnnas.com）、
   DaoCloud 免费镜像（docker.m.daocloud.io）、Docker Hub 官方仓库，前一个失败自动回退下一个。
3. 建议内存 ≥4GB；首次启动约需 1~5 分钟完成安卓系统初始化。
4. 安装向导会展示《免责声明》摘要、硬件要求与内核 binder 确认，需选择「同意并继续
   安装」方可安装。

三、使用要点
1. 从应用中心点击「打开」即可通过飞牛统一网关进入云手机画面；也可在局域网内直接访问
   https://<NAS_IP>:8443（默认账号 admin、默认密码 admin123，首次登录后请务必立即修改默认密码）。
2. 安卓数据保存在数据卷中；卸载时选择保留数据，重装后数据仍在。
3. APK 兼容性（含 x86 设备的 ARM 翻译层说明）与常见问题排查，详见 GitHub README
   （https://github.com/lin1740/fnos-android-emulator）的 FAQ 章节。
4. 权限声明：本应用无宿主 root 常驻进程（v3.6.5 起后台进程自动降权），全包仅安卓主容器
   （redroid）因上游技术方案必需以特权（privileged）模式运行，其余容器与脚本均为最小权限
   ——「容器内 root」不等于「特权容器」，也不等于「宿主 root」；完整口径见包内《权限说明》。
5. 本应用为飞牛 fnOS 非官方第三方应用，按「现状」提供，不提供任何明示或默示担保，
   请自行评估使用风险，并确保使用行为符合所在地法律法规与平台规则。
6. 当前版本默认禁用音频（redroid 容器内 Opus 编码器兼容性问题），未来版本将尝试修复；
   默认关闭蓝牙与串口控制台以提升性能，开发者可手动开启串口控制台用于调试。

【云手机 Agent 部署（容器内）】
若需在安卓容器内运行穿云投屏的云手机 Agent（让设备显示在线），信令与 TURN 地址请使用本包已注入的固定主机名 host.docker.internal（指向网桥网关），不要填宿主局域网 IP：fnOS 会拦截「bridge 容器 → 宿主局域网 IP / 127.0.0.1」，填局域网 IP 必然报 connect: network is unreachable，设备永远不上线。
现成命令可用包内脚本一键查看/部署/守护：
  bash $TRIM_APPDEST/scripts/agent_helper.sh show            # 打印复制即用的部署命令
  bash $TRIM_APPDEST/scripts/agent_helper.sh deploy <目录>    # 拷贝并启动 agent
  bash $TRIM_APPDEST/scripts/agent_helper.sh watchdog install  # 容器重建/agent 退出后自动拉起
